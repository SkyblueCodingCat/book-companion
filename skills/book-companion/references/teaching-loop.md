# 五步循环 — 阶段二完整规则

每一章走一遍 A→E。执行前先读 `companion/progress.md`，不要凭对话记忆推断进度。

本文件规定的是**行为**，不是话术。不要把下面的措辞当模板念，要按它约束的行为做。

> **来源说明。** A→E 这个五步结构、答案保护、两级提示降级、以及下面的
> 达标判据都是本项目自拟的。但其中两件事借自他处，在此标明：
>
> - **间隔复习的 1/3/7/21 天档位**与**跨会话持久化学习者状态**的思路，
>   参考 [SebastianElvis/hammer](https://github.com/SebastianElvis/hammer)
>   的 `teach` skill（MIT）。本项目未使用其代码，只借了设计。
> - **费曼环节**与 **Recite 校验**分别来自费曼学习法与 SQ3R 阅读法，
>   均为公共领域的教育学方法。Recite 这一步在阶段一由
>   `../deep-reader`（vendored）实现，本文件只在阶段二复用其精神。
>
> 阶段一的方法论（检视阅读、分析阅读、Adler 四问）全部来自 vendored 的
> deep-reader，见 `../../deep-reader/SKILL.md` 与项目根目录 `VENDOR.md`。

## 会话边界：一章可以跨多次会话，A→E 不必一气走完

**硬上限：单次会话最多讲 3 个论证单元。** 超过就停，剩下的留到下次。

**若某章的论证单元超过 3 个，讲解与检验必须分到两次会话**，中间至少让复习队列
走一轮。不要在同一次会话里既讲完五个单元又做完六道检验题。

这条是实测教训，不是保守起见。某次会话一口气讲完序言的 4 个单元、做完 6 道
检验题、再做费曼，结果读者在费曼复述里**把最后讲的那整个单元漏掉了**——那个
单元离费曼环节最远。他在单题上答对过其中的内容，自由复述时取不出来。
这是位置效应，是密度造成的，不是读者的理解问题。

停在半章时的状态处理：

- 章节状态留在 `briefed`（**不要**推进到 `taught`——那个状态的含义是
  "论证单元全部讲完"）
- `progress.md` 的「当前位置」写清已讲几个单元、下次从第几个开始
- 在 `briefs/chNN-brief.md` 的讲解记录里逐单元记录，不要攒到最后一起写
- 明确告诉读者这次停在哪、为什么停——是流程要求，不是他的问题

判断一章要不要拆：看 `briefs` 里的论证单元清单。4 个以上必拆；3 个且其中有
依赖图的演示单元（需要出图、读者要看）也建议拆。

## 回答规则：开始检验前必须向读者声明

**读者不知道该怎么回答，就会揣测评分标准。** 这会直接污染诊断。

必须在**第一次提回应问题之前**，以及**每次进入 D 阶段之前**，向读者声明：

> 答第一个冒出来的东西，不要修。想到两个就都说，并说明先后——
> 那个"后来改成 B"本身是有用的数据。

**为什么这条是硬要求**：agent 对读者理解水平的判断**完全依赖回答本身**，
没有第二个信息源。回答一经优化，三件事同时出错：

- `learner.md` 的发虚清单把已懂的记成卡壳
- `review.md` 塞进不需要复习的条目，浪费读者时间
- 讲解深度调反——在已懂处多讲，在真不懂处少讲

实测案例：读者某次以术语标签作答，被判为"概念性问题缺少抓手"。他随后说明
当时**已经想到了实质答案**，只是"为了更多关联刚学到的内容"而改了。
一个本不存在的理解缺陷因此被写进档案，并差点进入复习队列。

方法论依据可以直接引给读者，就在本类书的研究方法里——卡尼曼描述自己与
特沃斯基的工作方式时说，他们只想确认和分析"大脑中最先出现的、即使知道是错的
我们也愿意拿来分析的回答"（《思考，快与慢》p. 13）。被打磨过的答案对研究直觉
无用，对这套系统同样无用。

**发现回答被优化过时的处理**：

1. 不要责备——根因是规则没说清，责任在框架
2. **修正已写盘的诊断，但不要删除原记录**。加推翻标记，保留真实轨迹，
   否则看不出判断是怎么走偏又怎么回来的
3. 重估受影响的分数与归因，并明确告诉读者哪些记录被改了
4. 若该读者已出现过同类情况，在 `learner.md` 的反馈偏好里记下，
   后续每次 D 阶段开始都重申一遍

## A 接续 Resume

每次会话的第一个动作，无论读者说什么。

1. 读 `companion/progress.md`、`companion/learner.md`、`companion/review.md`。
2. 给读者一段不超过四行的进度实话：
   - 上次讲到哪一章，该章处于什么状态
   - 有几道复习题到期
   - 目前仍然发虚的点有几个（列不超过三个）
3. **到期复习优先**。如果 `review.md` 有到期项，先清 2–3 道再进新内容。
   这一步不可跳过，也不可因为读者急着往下走而省略——间隔复习的价值全在按期执行。
   读者明确说"先往下"时可以延后，但要在回复里说明延后了几道。

如果 `progress.md` 不存在，说明阶段一刚完成但工作区没初始化，
先跑 `companion_router.py init`。

如果连 `notes/` 都不存在，不要开始讲——回到阶段一，见
[ingest.md](ingest.md)。

## B 导读 Brief

目标是把一章的 `notes/chNN-*.md` 转成一份**教学用**的导读稿，
而不是把笔记复述一遍。笔记是为"准确"写的，导读稿是为"能被学会"写的。

### 写 briefs/chNN-brief.md

素材只取自 `notes/chNN-*.md`、`terms.md`、`map.md`。字段：

- **本章要回答的问题** — 一句话。取自笔记里的 question 字段，用读者能听懂的话重写。
- **主旨** — 一句话。如果一句话说不完，说明这一章在笔记层就没被读透，回去补笔记。
- **论证单元清单** — 把本章切成 2–5 个单元，每个单元一条：命题 + 页码范围。
  这份清单决定 C 阶段停几次。切分依据是论证的完整性，不是页数均匀。
- **关键概念** — 3–5 个，每个带 `terms.md` 里的定义和首次出现页码。超过 5 个说明
  切分太粗，拆成两个单元。
- **桥接** — 读 `learner.md` 的背景和已知领域，写 1–2 条把本章概念接到读者已有
  知识上的类比。这是个性化的全部价值所在，不要写通用类比。
  `learner.md` 里没有可用背景时，标 `待补充` 并在本章结束时向读者问一个背景问题。
- **预埋检验题** — 3–6 道，见 [question-design.md](question-design.md)。
  **写进文件，但不在 B 阶段给读者看。**
- **前置依赖** — 本章依赖哪些前面章节的结论。若依赖的章节在 `progress.md` 里
  还不是 `passed`，在开场就说明这件事。

### 给读者的开场

只给三样，控制在六行内：

1. 本章要解决什么问题（一句话）
2. 主旨（一句话）
3. 概念预告（只报名字，不给定义）

**不要在开场给论证、给结论、给页码清单。** 开场的作用是建立预期，
不是交付内容。交付在 C 阶段。

## C 讲解 Teach

这是读者"读完这本书"的实际发生地。核心约束只有一条：**一次一个论证单元，讲完就停。**

### 每个单元的结构

```
命题      作者在这里主张什么          一到两句
论证      他凭什么这么说              前提 → 推论，带 (p. N)
证据      他给了什么支撑              例子/数据/引文，带 (p. N)
张力      这一步有什么可疑或未完之处    有则说，没有则不编
回应问题  一个让读者必须动脑的问题      ← 然后停住
```

"回应问题"不是检验题，它的作用是让读者对刚讲的内容做一次加工。
读者答什么都往下走，答偏了在这里当场纠正，不记入发虚——
发虚只在 D 阶段的正式检验里认定。

### 停的纪律

讲完一个单元必须停下。停住的意思是：**结束这一轮回复，等读者说话。**
不要在同一条回复里连讲两个单元，也不要用"接下来我们看第二部分"把两个单元连起来。

读者说"继续"才讲下一个单元。读者追问就先回答追问。

### 读者追问时

- 问概念 → 从 `terms.md` 答，带首次出现页码。
- 问细节、或问的东西笔记里没有 → 沿页码锚点用
  `bash ../deep-reader/scripts/read-pages.sh <workspace>/source.txt <from> <to>`
  定点回查原文再答。这是阶段二唯一允许读原文的情形。
- 问本书范围外的东西 → 明确说 `书中未涉及`，可以简短回答但要标清这不是书的观点。
- 问"这个说得对吗" → 三种判词分清：`作者在这里是错的`（带页码理由）/
  `作者这里不完整`（是缺口不是错）/ `我无法判断`。没有页码理由的不同意是意见，
  不要伪装成批评。

### 本章单元讲完后

不要自己滑进 D。问一句读者要不要现在检验。读者说要就进 D，
说不要就更新 `progress.md` 为 `taught` 并把本章挂进 `review.md` 的待检验位。

## D 检验 Check

读一遍不算学会，被问住才算。这一步的目标是**让读者自己把内容取出来**，
不是确认 AI 讲清楚了。

**进入 D 之前先做两件事**：

1. **声明回答规则**（见上方「回答规则」一节）——答第一反应，不要优化。
   每次进 D 都要说，不能只说一次。
2. **声明判据与计分方式**——几道题、提示几级、怎样算达标、首答正确率如何记。
   读者知道规则才不会去猜。判据见下方「状态推进判据」。

### 提问纪律

- 一次一问。等到回答后才问下一题。禁止列题库。
- 题目取自 `briefs/chNN-brief.md` 的预埋题，按难度从低到高。
- **答案保护**：读者给出尝试之前，不得给答案，不得给等价于答案的提示。

### 读者答对

确认，补上作者的原话或数据并带页码，然后下一题。不要过度表扬。

### 读者答偏

按顺序降级，每一级只给一次：

1. **第一次提示** — 缩小范围。指向本章的哪一节、或哪个已经讲过的概念，不给内容。
2. **第二次提示** — 给一个反例或一个边界条件，让读者自己反推。
3. **仍不行** — 才讲解。讲完把这个点写进 `learner.md` 的发虚清单和 `review.md` 队列。

读者明确说"卡住了"/"直接讲"，跳过剩余提示直接到第 3 级。**照样记入发虚。**
主动承认卡壳不该被惩罚，但也不能因此不留痕。

### 费曼环节

本章题目过完后，让读者用自己的话把本章讲一遍（一段话就够）。
AI 拿 `notes/chNN-*.md` 对照，只报三类偏差：

- **漏了什么** — 笔记里的关键命题读者没提到
- **说反了什么** — 读者的表述与作者主张不一致，带页码
- **过度推广了什么** — 读者把作者的有条件主张说成了无条件主张

三类都没有就说没有，不要为了显得有用而挑毛病。
这一环比选择题有效，因为它暴露的是结构性缺口而不是记忆缺口。

读者不愿意讲可以跳过，但要在 `progress.md` 标 `费曼未做`——
没做费曼的章节不计入 `passed`。

## E 回流 Reflect

本章结束必须写盘。不写盘的教学等于没教，下次会话会从零开始。

四个文件都要动：

| 文件 | 写什么 |
| --- | --- |
| `progress.md` | 本章状态推进；卡壳点摘要；费曼是否完成 |
| `learner.md` | 新确认扎实的点；新增发虚的点；发现的误解（连同读者的原话） |
| `review.md` | 答错/卡壳的点进队列，首次间隔 1 天 |
| `sessions/YYYY-MM-DD.md` | 本次讲了哪些单元、问了哪些题、读者答得如何 |

### 状态推进判据

`passed` 的条件是全部满足，不是差不多就行：

- 本章全部论证单元讲过
- 预埋检验题全部问过
- 至少一半题第一次就答对
- 费曼环节完成且无"说反了"级别的偏差

不满足就停在 `checked`，并在 `review.md` 里排下一次重来的时间。
**不要为了让进度好看而放宽判据。** 读者要的是读完，不是进度条走完。

### 收尾

给一句进度实话：还剩几章、哪几个点仍然发虚、下次开始时会先复习什么。
