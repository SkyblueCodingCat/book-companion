# books/

把你**有权阅读**的书放这里。

## 支持的格式

| 格式 | 推荐度 | 说明 |
| --- | --- | --- |
| **EPUB** | 首选 | 正文零损失、章节标题保留、**插图可提取** |
| **PDF（文字版）** | 并列首选 | 唯一有真实页码的格式，但须抽检是否缺字 |
| FB2 / DOCX / ODT / RTF / HTML | 可用 | 保真度同 EPUB，但书源罕见 |
| Markdown / TXT | 可用 | 零转换损失，但**无章节结构**，定位要多花一步 |
| MOBI / AZW / AZW3 | 不支持 | 先用 Calibre `ebook-convert` 转 EPUB |

EPUB 优于 PDF，这与直觉相反。原因与实测数据见
`skills/book-companion/references/ingest.md` 的「源文件格式的选择」。

PDF 的风险是**静默缺字**——字体没有某个字的字形时渲染留空白，提取出来是空格，
句子读着依然通顺却不报错。`prepare_source.py` 的输出里有 `quality` 字段自动审计
（判据是汉字之间不该有空格），判为可疑时务必抽查原文。

## 跑过之后

每本书会在同目录生成一个工作区：

```
books/
├── 如何阅读一本书.epub
└── 如何阅读一本书-notes/     ← 全文、切片、笔记、插图、companion/ 状态
```

## 这个目录不入版本库

`.gitignore` 排除了 `books/` 下除本文件和 `.gitkeep` 之外的一切，原因有两条：

1. **书有版权。** 本项目不包含任何书籍内容，也不应该帮你分发。
2. **工作区是高度个人化的学习状态**——里面有你的答题记录、误解原话、进度分数。

需要备份时单独同步 `<slug>-notes/companion/`，那里面全是纯 markdown，
体积小，是你真正积累下来的东西。注意它包含个人学习记录，
**同步到公开位置前想清楚**。
